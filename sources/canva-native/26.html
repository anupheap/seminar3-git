Conclusion

  • Linear Independence: Equivalent to N(A) = 0, tested by placing vectors as
    columns of A and checking for free variables.


  • Spanning: Extends the definition of column space C(A) as all linear
    combinations of columns.


  • Basis: Combines independence and spanning. For R^n, checking if n vectors
    form a basis is equivalent to testing matrix invertibility.


  • Dimension: Bridges matrix rank r to geometry: dim(C(A)) = r and dim(N(A)) =
    n - r.
